# Support

Use GitHub Discussions for setup questions and design conversations once
Discussions are enabled. Use GitHub Issues for reproducible bugs and accepted
feature requests.

Before opening a support request:

1. Read `README.md` and the relevant document under `docs/`.
2. Search existing issues.
3. Reproduce the problem from a clean install.
4. Remove tokens, secrets, private repository names, and personal data from
   logs and screenshots.

Security vulnerabilities must follow `SECURITY.md` and must never be posted
publicly.
